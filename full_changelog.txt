CRUS REVITALIZED FULL CHANGELOG

SINGLEPLAYER AND ONLINE
- Separated normal singleplayer play from Online so starting a mission offline no longer quietly creates a local multiplayer server. The game now switches between the normal game flow and the Online lobby depending on whether a multiplayer session is actually active, while keeping multiplayer menus, synchronization screens, voice input, network-only controls, etc out of ordinary singleplayer play
- Kept both LAN and Steam multiplayer and moved them onto the same Online menus, mission rules, and networked gameplay systems. Discord Rich Presence also shows the correct Singleplayer or Online state, and normal menu control is restored when a host ends a session or a client disconnects

LOBBIES AND JOINING
- Added a browser for compatible public Steam lobbies. It shows each lobby's name, game mode, player count and capacity, and estimated ping. You can join a listed lobby by double-clicking it or by using Join, and the list can be manually refreshed at any time. Unchanged host settings no longer repeatedly republish the lobby type, and browser rows update when Steam delivers their metadata. Previously found lobbies are checked directly before being removed after a search omits them. Estimated ping uses Steam relay location data and updates as measurements become available
- Added editable lobby names with a Steam name-based default, and replaced lobby passwords with six-character alphanumeric lobby codes. Direct Join can use these codes for public, friends-only, and private Steam lobbies, while the hosted lobby code stays hidden until its display is clicked
- Added Public, Friends Only, and Private lobby types, including Steam friend joining for Friends Only. Steam and LAN sessions can also set a maximum player count (250 for Steam, 4096 for LAN)
- Added compatibility checks so unrelated CruS Online lobbies and mismatched Revitalized builds do not appear as joinable public lobbies. Joining now stays on the connection screen until the connection actually succeeds or fails, with clearer handling for invalid codes, failed connections, cancellation, full lobbies, and hosts closing the session
- Reworked the Online flow so hosting and joining remain on the Main Online tab instead of unexpectedly changing tabs. Choosing LAN or Steam opens the appropriate host settings, and host settings can continue being changed and synchronized while a lobby is already running
- Expanded host settings with progress saving, revive rules, friendly fire, shared difficulty, voice behavior, bans, spawn invulnerability, death weapon drops, etc. The lobby also has a player roster showing host, readiness, voice, and mute information
- Added client ready controls in level select. The Ready button occupies the same position as the host's Start button, and the host sees a Ready: #/# count. The host cannot start if there are fewer than 2 players in the lobby. When a match cannot start or a mission is unavailable for Counter-Opps, the reason is shown through the UI tooltip
- Clients see the host's selected mission in the square beside Ready, with the full mission and typing handler sidebar alongside it. The preview updates when the host changes their selection, and Punishment and Chaos controls are unavailable to clients
- Added third-person spectating from the death screen, enabled by default through a host setting. The camera can zoom in and out, and uses the strafe controls to cycle through living players. A target dying or leaving switches to another eligible player or returns to the death screen, while revival restores the player's own camera. Counter-Opps restricts spectators to teammates unless the host enables opponent spectating; that option is unavailable if spectating is disabled
- Kept Return to Level Select and Return to Menu available to non-hosts during a mission. Clients can leave an active mission and wait in the lobby without ending it for everyone else, and competitive matches now handle the last other player leaving without trapping whoever remains

ONLINE MODES
- Completely reworked Deathmatch. Players are spread around valid civilian and fallback spawn positions instead of stacking at the normal player spawn, and the host can choose whether enemies and civilians remain in the level. Deathmatch ends when only one player remains alive and announces that player as the winner. Enemy and civilian result counts are omitted when Deathmatch NPCs are disabled, and Deathmatch wins and losses are tracked separately
- Added a new Counter-Opps gamemode with Operative and Counter-Operative teams. Counter-Operatives spawn around mission positions normally used by civilians instead of at the Operative spawn, and the mode has its own team, objective, revival, and victory rules
- Counter-Opps has options for enemy friendly fire and whether attacked friendly enemies should turn hostile to Counter-Operatives. Teams can be player-selected using the switcher on the menu, host-assigned, or randomized each round, with randomized assignment balanced. CSHQ and Trauma Loop are the only missions unavailable for various reasons
- Random team selection is disabled while host team overrides are active. Counter-Opps uses team-specific result messages, unavailable mission portraits are shown in red, and wins and losses are tracked separately from Deathmatch
- Result screens immediately return positional voice chat to normal conversation
- Deathmatch and Counter-Opps allow all difficulty doors to open regardless of the player's difficulty state, mainly to prevent getting stuck. Preplaced weapon and implant pickups are removed from their maps

MISSION FLOW, OBJECTIVES, AND PROGRESSION
- Reworked Online mission starts, scene changes, restarts, exits, failures, and results as shared host-directed events. The synchronization screen shows how many players have finished loading
- Mission objectives are synchronized between host and clients, including both the original total and the number still remaining. Clients receive the normal "target eliminated" and "all objectives complete" announcements, and Discord presence counts the actual live mission targets, including difficulty-specific cases such as CSHQ. Deathmatch presence shows remaining players instead
- Mission targets publish their authoritative health and death state so clients stay consistent with the host, including the HQ Life target. Health and armor updates are grouped rather than sending a reliable message for every damage tick. On Steam, deaths and mission transitions use a separate reliable channel so heavy combat traffic cannot hold them behind ordinary updates. Ending results remain valid across scene transitions so the HQ ending cutscene starts for the whole lobby
- Online results use the game's normal level-end presentation and send the same mission time, enemy and civilian counts, difficulty, rewards, and ending result to everyone. Normal campaign progression applies to Online wins as well, including money, weapon and level unlocks, Punishment rewards, endings, and any failure penalties or difficulty changes the game normally requires. The Cruelty Squad Headquarters, Archon Grid, and Trauma Loop endings stop on their final shot, cut the music, and show mission results. Only the successful Trauma Loop ending cutscene gives its results a single Next button, which opens the credits for everyone in an Online lobby; dying in Trauma Loop or finishing a competitive match there does not. Online credits return the lobby to the main menu when finished or skipped; in Singleplayer, letting them finish restarts at the Consumer Softproducts opening scene, or goes straight to save-slot selection when Skip Intro is enabled. Skipping them returns to the main menu
- Mission exits only wait for living players who are actually participating in the mission, so dead players and players waiting outside the mission do not block completion. The exit is checked again before a transition is committed to make sure the living players are still inside.
- Competitive wipes no longer leave the final revive message hanging over the result screen, and missions can be restarted directly through the shared results flow.
- Immortal enemies no longer inflate the enemies-killed total. The same killable-enemy definition is used by the Controlled Depopulation goal.
- Restored the flying-head death camera and dismemberment in singleplayer, with the whole level continuing to run behind failure results. Permanent Online deaths also break into synchronized gibs and blood, while revivable players retain their bodies. Results hide the entire level-select sidebar
- Added a host option to drop carried weapons on permanent death so other players can collect them. Players who can still be revived retain their loadout; drops occur when reviving is disabled or their revive allowance has been exhausted

DIFFICULTY AND SHARED WORLD STATE
- Added Share Difficulty so a lobby can use the host's Life or Death state, Hope Eradicated, Punishment, and Chaos conditions. Each client gets their own difficulty state restored when the shared-difficulty session ends.
- Difficulty is shown using readable names such as Flesh Automaton, Divine Light, Power in Misery, and Hope Eradicated. When Share Difficulty is disabled, the host's state is still kept as session information without overwriting anyone else's save.
- Change Mode on Death now goes through the same synchronized mission-failure flow as the rest of Online.
- Mission weather, time of day, relevant ending state, rain, storms, and special sky behavior are synchronized across players. Players entering an already active session are sent the current world and difficulty state, while identical difficulty state is not repeatedly retransmitted for no reason.
- Soul and orb use is validated through the host so the same orb cannot be consumed twice.

REVIVES, DEATH, AND PLAYER INTERACTION
- Reworked dead and alive player tracking across missions, loading, spectating, and results so the session always agrees on who is actually active.
- Added teammate revival with host-validated range, player state, and revive availability. Both client-to-host and host-to-client revival paths work in Cruelty mode, with configurable revive delay and either limited or unlimited revives per player. Reviving restores weapon processing and the carried loadout, keeping shooting, reloading, and pickup exchanges usable
- Self-revival remains a separate host option where the selected mode allows it. Counter-Opps restricts teammate revives by team, while Deathmatch disables revives entirely.
- The final active player's death is handled as a proper team wipe instead of waiting on players who already left the mission. Client departures are also kept separate from active deaths so they do not continue blocking mission completion.
- Reworked Augmented Arms+ player carrying and throwing so non-hosts can interact with both players and physics objects correctly.

PLAYER MOVEMENT, APPEARANCE, AND SOUNDS
- Reworked remote movement around replaceable snapshots so an older position update cannot drag a player backward after a newer one arrives. Remote aim, crouching, gravity, sitting, flashlight use, weapons, death, grappling, and long-frame interpolation were all improved, while grapple rendering work was reduced. Player positions now continue updating when weapon hold positions are included, restoring visible remote players and positional voice chat. Flashlight visibility is sent only when it changes, reducing reliable network traffic
- Dead enemies now put away their hand-held weapon on non-host screens as well as on the host
- Added collision bodies for remote players that follow crouching and death state. Knockback is synchronized, and remote players now reproduce more footsteps, jumps, pain, healing, armor, death, and explosion sounds. Footsteps use each remote player's own equipment state, so the Golem Exosystem sound is heard only from its wearer.
- Player nickname and color changes can refresh while connected. Nameplates are centered more reliably, hidden beyond 12 world units, and use the game's normal compact drop shadow instead of the larger distant outline.
- Fixed remote outfit UV mapping so text and patterns are not mirrored across the torso.
- Level VI Golem Exosystem users now use a golem player model with Triagon-style material and animations. Its ground placement and nameplate height were adjusted separately so the model sits correctly without lowering the nameplate.
- Cortical Scaledown+ visibly shrinks remote player models and their collision bodies, including the Golem model. Nameplates and revive text move with the smaller body while retaining their normal text size

ENEMIES AND MISSION SYSTEMS
- Expanded enemy targeting so enemies consider every valid living player instead of only the host's local player. Civilians can flee from nearby multiplayer players, dead players are ignored as targets, and gameplay decisions remain authoritative to the host while visible results are replicated.
- Enemy and civilian population, objective registration, deaths, removals, and weapon drops are synchronized. Late joiners no longer see defeated enemies come back alive simply because they loaded the mission later.
- Enemy muzzle flashes are synchronized, and sight or psychosis effects are sent to the player actually being watched instead of assuming the host is the target.
- Enemy movement update frequency is reduced according to distance from nearby players to cut unnecessary work.
- Added networked handling for special bosses, flesh rats, cancer conversion, Hell and Chaos objectives, mission-specific interactions, visible gunk, and similar projectiles or effects.
- NPC animation handling is more tolerant of models that do not contain every expected animation name.

COMBAT AND WEAPONS
- Golem Exosystem punches now strip armor before applying their normal impact damage. The Bolt ACR's direct beam likewise damages armor, while its lingering radiation keeps its existing behavior
- The Parasonic D2, Minato M9, and Parasonic MP-1 now hide the center crosshair while equipped, leaving their laser dot as the aiming indicator
- Added custom weapon packages installed in the game's weapons folder alongside levels and campaigns. Each package can provide descriptions, ammunition, damage, armor piercing, art, sounds, models, pickups, and map entities; Online discovers its manifest when the game starts. Map pickups and enemy carriers refer to a stable weapon ID instead of a numbered slot. Ordinary hitscan firing and synchronized projectile secondary attacks have reusable behavior, while unusual mechanics can use a custom script. Multiplayer models use named muzzle-flash and audio nodes rather than child order. All players still need matching weapon packages because parts of the original weapon replication use runtime slots
- The Herschel Firearms F2500 is a separate, self-contained custom weapon example with its own menu, first-person, remote-player, pickup, enemy, and grenade assets. It is a 30-round assault rifle with an optic and impact grenade launcher that follows the rifle's aim and produces a lethal blast and damaging shrapnel. Shoot Secondary is a separate, rebindable control set to middle mouse by default; the original tertiary control remains available for implants. The F2500 starts with 135 spare rifle rounds and three spare grenades, while the Load Bearing Vest raises those reserves to 180 rounds and four grenades. Its secondary ammunition appears above the normal ammo display, and it can be placed as a map pickup or carried by a Cult of Order SWAT variant
- Bullet casings and weapon impact marks are shared with other players during Online missions
- Added a Friendly Fire host option while preserving self-damage and environmental damage. The same player-damage rules now apply consistently to direct hits, explosions, fire, radiation, grenades, missiles, vehicles, and thrown objects.
- Bolt ACR radiation retains the player who created it as its owner, leaves that player unharmed, and respects friendly-fire rules for other players. Overlapping spray limits particle emitters, clients skip unnecessary damage-area processing, and host overlap checks are staggered while retaining radiation damage over time. Death-only atmosphere checks each player's own matrix, including non-hosts
- Chained damage effects preserve the real attacker's identity for kill attribution and team rules, and player-damage claims are validated against the sender and the action's actual source.
- Grenade and missile damage remains authoritative while their visible effects are synchronized.
- Improved multiplayer handling for the baton, Snoozefest, sedatives, and other weapons with status effects. The dark, distorted, slowing gas effect is restricted to Special Sedative Grenade+ rather than the normal implant, lasts ten seconds, and ignores the thrower plus Level V and VI suits.
- Reworked shared weapon pickups so the host approves a pickup or swap before it takes effect. Two players cannot consume the same pickup at once, and ammunition-only pickups, replacement weapons, consumed pickups, and rejected pickups are all synchronized.
- Networked weapon pickups validate weapon IDs, ammunition values, interaction range, and weapon audio.

PHYSICS OBJECTS AND INTERACTIVE LEVEL ELEMENTS
- Reworked multiplayer props around host-approved holding, releasing, throwing, and settled states. Prop movement is rejected from players who do not currently own the held object, and stale transforms can no longer snap a dropped or removed prop back into someone's hands.
- Held objects are released when their holder disconnects, collisions against the carrier are reduced, and thrown-object damage keeps its correct attacker attribution. Special radio throws and remote physics impacts are synchronized as well.
- Multiplayer blood decals are limited and distant or inactive props update less frequently.
- Reworked doors and elevators so movement and final open or closed state are host-owned. Delayed updates no longer restore an old door position after movement has already finished, and the elevator movement sound loops until it stops
- The car supports a driver and three passengers with host-assigned front and rear seats, individual entry and exit, and synchronized occupancy. Occupants are excluded from car collisions so passengers cannot push it around. Only the driver controls movement; passengers have their own seated camera with the configured vertical look direction, interaction indicators hide while seated, and seats are released when occupants leave
- Triagon targeting, laser attacks, activation, health, and deaths follow the host's simulation. Killing one grants its reward to every player and creates the same falling head across the lobby while preserving the remaining animated body
- Miner's Miracle's sniper camera activates and releases only for the local player entering or leaving its trigger, so another player's movement cannot take over everyone's view. Dying releases the camera and disables its weapon
- Switch use and spiritual-door interactions are validated against player position and state. Terror door destruction, destructibles, pushblocks, rotating objects, paintings, slot machines, and other interactive props are synchronized through the session.
- Added synchronized cancer growth and destruction with limits on how much spread and damage processing can happen in one frame.

STOCK MARKET AND EQUIPMENT PRICES
- Reworked company shares into a dynamic market with distinct calm, growth, decline, and crash periods. Companies can gain or lose substantial value over a campaign, including recovery from ordinary downturns, while mission-driven changes unfold over time instead of dropping a share price in a single tick. Existing holdings and prices remain in their save slots
- Added a Market Outlook panel below the shorter stock list. It describes the effects of built-in missions with market events and places rising and falling tickers on separate lines without revealing exact percentages. Archon Grid and Trauma Loop list every company ticker individually. Secret mission forecasts appear once unlocked, while Cruelty Squad Headquarters requires Hope Eradicated and Death mode to have been active together at least once in that save slot. A successful takeover of Cruelty Squad Headquarters sharply raises Cruelty Squad shares and damages Security, Redefined. House has no market event, and the panel says when no forecasts are available. After completion, the latest mission's exact impacts appear to the right of the Outlook heading only while the 20-second price movement is active. Mission events occur once per save slot. Mall Madness sharply raises GamesGames, Apartment Atrocity bankrupts it, and Archon Grid later revives it while nearly doubling every company stock; Trauma Loop brings every company stock close to zero. Fish and body parts are unaffected by these market-wide events
- Linked implant purchase quotes to the market value of related companies. Head, torso, leg, and arm equipment respond to different shares, and an open implant tooltip shows its live price beside the relevant stock ticker while the equipment menu is open. Price changes are capped so market conditions affect planning without making equipment unobtainable. Fish and body parts retain their existing price behavior

ONLINE EQUIPMENT AND IMPLANTS
- Added Online extension implants with their own inventory art and tooltips.
- Military Camouflage+ makes a player fade with a regular Bayer dither starting at nine units and become hidden by twelve. Stealth Suit+ uses the shitman-style optical material with a half-transparent dithered appearance. Both effects apply to the full visible player model, including glasses.
- First Aid Kit+ heals a nearby player for 50 health through interaction instead of healing the wearer.
- Special Sedative Grenade+ applies a synchronized dark, distorted, slowing gas effect to other players.
- Cursed Torch+ restores health after killing another player.
- Augmented Arms+ can carry and throw other players in addition to physical objects.
- Cortical Scaledown+ has its own higher-pitched voice effect.
- Added a Bans tab with equal-width Implants and Weapons selectors above a scrollable icon grid. Both categories support live banning, Ban All, Allow All, and separate saved presets. Banned weapons are blocked in loadout selection and pickups, removed from carried and revive loadouts, and marked in the weapon menu; banning both carried weapons safely leaves the player unarmed. Custom weapons use stable package IDs for saved bans. The normal equipment menu updates its banned tint and tooltip live when the host bans or allows an implant, including while its tooltip remains open. Banned implants are removed from equipped slots when the settings arrive, without removing ownership. Undiscovered items retain their icons in the Bans grid but show ??? for their names and descriptions. Removed the unused dead-player implant picker and its dedicated assets

SURVEILLANCE EYECAMS
- Added Surveillance Eyecam as a PURE ocular implant for scanning visible players within 15 units, including Golem Exosystem users. It draws an expanding one-pixel tracking rectangle around the visible player model, contracts when the target leaves view, and reveals money, health, Life or Death matrix, equipped implants, and carried weapons after a three-second analysis
- A scan is forgotten once the target leaves view, so reacquiring them requires another analysis. Scan acquisition audio is synchronized, and the equipment and weapon readouts animate as the information is revealed.
- Added Surveillance Eyecam PRO MAX as an ocular implant developed by PURE for Security, Redefined, with pricing tied to SCRD shares. It locks the user's camera and body onto the nearest player within ten units, using a three-second lock-on, a ten-second initial delay, and a 45-second cooldown
- Once PRO MAX acquires a player, that target remains locked for the full sequence even if they move out of range. The hijack sound plays at acquisition, the target gets a red flickering hijack warning, and one of their weapons or implants is disabled for 15 seconds. A jammed firearm can still reload.

PNEUMATIC MERIT PUMP
- Added the Pneumatic Merit Pump arm implant, which turns held-up personal funds into a throwable money pickup. Holding the tertiary-weapon input raises the amount exponentially with audible cash ticks, and releasing throws the cash forward for another player or NPC to collect. The owner cannot reclaim their own drop.
- The pump can be overdrawn into a negative balance, but the actual dropped amount is limited to the money the player really possessed. Holding it all the way to twice the available balance causes an audible overload and an IED-style death without dropping the money.
- Hostile NPCs can take thrown cash as a bribe and become passive once their asking price is met. Ordinary human enemies use randomized asking prices from $50 to $500, necromechs ask for more, and Abraxas or the HQ Life boss ask for more again.
- Human NPCs immediately tell the payer whether the bribe was accepted or how much more money they still want.

VOICE CHAT AND COMMUNICATION
- Added built-in LAN and Steam voice chat with Push-To-Talk, voice activation, microphone selection, and volume control. Push-To-Talk defaults to V and can be rebound to a keyboard key or mouse button, while voice activation automatically stops while typing into a text field.
- During missions, voice is positional and comes from the speaker's character. Hosts can switch to non-positional voice and decide whether living players can hear dead players.
- Dead players use reverb, underwater speech is muffled, and dead players can still talk to each other normally without positional treatment. Results screens restore ordinary lobby-style voice instead of leaving the last death's spatial effects active.
- Added talking indicators, local per-player mute controls, and host-enforced global voice muting through chat commands.
- Added equipment-specific voice effects for helmets, biosuits, speed enhancers, golem armor, Bouncy Suit, Abominator, Goo Overdrive, Cortical Scaledown+, Hazmat Suit, Holy Scope, and Stealth Suit+. These effects can combine with underwater and death processing without leaking the wrong treatment into menus or results.
- Abominator reversal depends on both the speaker and listener: two inverted players hear each other normally, while upright and inverted players hear each other in reverse
- Added microphone device fallback, missing-microphone warnings, and voice diagnostics. Delayed audio queues are capped, stale or duplicate voice packets are rejected, oversized and wrong-session packets are ignored, and voice volume remains independent from the game's normal master volume.
- Improved chat window dragging, text scaling, and screen-edge containment. Open Chat defaults to T and can be rebound in Controls; it opens the in-game chat without the pause grid, focuses typing while keeping the cursor captured and player controls inactive, and closes after sending or pressing Escape. Opening the pause menu closes this typing view.

GOALS AND MASTERY
- Added an in-game Goals menu containing individual achievement portraits, names, descriptions, and rewards. Goals can be browsed through Campaign, Online, Extras, and Mastery categories, each with its own completion count. Clicking the category row advances to the next category while its name and count turn green on hover; the green header number shows the current category. The phone view follows cursor movement immediately, and achievement cards have no colored outer outline
- Every goal has a visible slot in its category. Secret goals show "???" for their name and description and a secret portrait until their associated level is beaten or their reveal condition is met. OPEN YOUR EYES remains secret until earned, while THE UNHOLY TRINITY is revealed when Trauma Loop is unlocked
- Added rotating phone goal notifications with the goal portrait, title, reward sound, and a sequential queue. Goals and their money rewards are awarded immediately even when several notifications are still waiting to play.
- Added per-mission mastery objectives for S rank, Hope Eradicated, Punishment, Chaos, Extravagant Suit, and no implants. Every campaign mission has its own mastery goal, ordered by mission in the Goals list; its progress count opens a two-row icon grid when clicked. The campaign-wide mastery goals show how many missions meet their condition without acting as buttons, while the regular campaign completion goals stay focused on clearing each mission. Hovering a mastery icon shows its name and requirement, while undiscovered conditions use the mystery portrait and hide their requirement. Known objectives that have not been completed use the disabled-button image, and their descriptions state what to complete. The stripped condition uses its own icon, mission names fit on one line, and leaving and reopening Goals restores the goal list. The upper panel uses the tiled implant texture and the lower panel uses the goal-card texture tinted green
- Undiscovered mastery conditions remain hidden until the relevant systems have been found, including Hope Eradicated, Chaos, and the Extravagant Suit. SYNAPTIC CASCADE, SUFFERING FOR AEONS, and BEAUTY OF LIFE occupy secret slots until Hope Eradicated is discovered, Chaos is unlocked, or the Extravagant Suit is purchased, respectively. DIVESTATION uses each mission's saved Stripped mastery result, including existing clears, and awards its goal once Stripped is complete across the campaign
- Existing saves can backfill goals using mission completion, times, difficulty records, and other saved progression. Financial Ascension unlocks when the current value of owned company shares reaches $1,000,000; cash, fish, and body parts do not count. Goal and mastery progress is stored separately per save slot and clears with that slot's save data

STATISTICS, PROFILES, AND SAVE SLOTS
- Added a Statistics screen with an animated full-quality player preview and an in-scene background that follows time of day and special difficulty skies without applying rain or other weather. Player-name editing, name color, and outfit selection were moved out of the Online profile tab and into Statistics.
- Clicking the previewed body cycles outfits and gives the body a visible hover outline so the interaction is obvious.
- Statistics shows completion, money, kills, deaths, playtime, weapons, equipment, fish, body parts, and goals in one profile. Collection statistics show unique finds out of the actual game total instead of counting repeated pickups, and playtime is displayed as hours, minutes, and seconds. Wearing the Level VI suit is shown simply as Golem Exosystem in the outfit field.
- Player kills, Online Equipment, and Total, Deathmatch, or Counter-Opps wins and losses are shown separately from the normal campaign statistics.
- Added a completion percentage that can extend beyond the base game's 100% through mastery and Online goals.
- Added four save slots after the opening sequence, with existing saves assigned to Slot 1. Hovering a slot with data shows a read-only player preview and detailed progress for that save, including a money value with enough room for larger balances; cleared slots remain empty without a preview until selected again. Settings and Quit to OS are available below the four slots before entering a save, with Settings opening on the left without the Modloader status text, save-reset controls, or Credits button

- Clear Save Data resets the selected slot's market events and active company trends along with its other progress, then returns to the save-slot selection screen.

CUSTOM MISSIONS, CAMPAIGNS, AND MOD COMPATIBILITY
- Added direct integration with CruS Mod Loader and CruS Mod Base. Mod Base's own custom-mission navigation and menu additions are preserved instead of being replaced with a separate imitation.
- Custom mission portraits, descriptions, handlers, targets, and results load through the same level-select flow as regular missions.
- Added a campaign format with ordered stages, unlock requirements, secret missions, and save-slot-specific progress. The built-in campaign is shown as Cruelty Squad, while loose Mod Base levels appear under Custom Missions.

Installation replaces the content after the game closes so loaded files do not block updates, then restarts and automatically rejoins the lobby.

- Debug builds also have commands for invulnerability, noclip, map selection, healing, revival, killing, money, weapons, implants, entity spawning, mass NPC removal, and AI freezing. /map list, /give list, and /spawn list return complete catalogs in chat, splitting long results into bounded messages. Mission and weapon lists include usable IDs, installed custom missions and weapons are included, and entity lists show full resource paths to avoid ambiguous names. Weapon lookup uses the weapon catalog rather than menu-child positions. /spawn accepts entity scene names or full resource paths, including vehicles and unused entity scenes
- F2 toggles the interface, crosshair, scope, target indicators, and difficulty border for clean captures. F3 independently toggles the held weapon and hands. Both shortcuts work during missions in release and debug builds

NETWORKING, RELIABILITY, AND PERFORMANCE
- Reworked the original Steam transport while keeping its underlying Steam P2P and LAN support. Protocol and build compatibility are checked before incompatible clients can enter gameplay.
- Reliable gameplay events are separated from disposable movement and state snapshots. Rapidly changing snapshots are batched, obsolete updates are replaced by newer ones, and stale movement, prop, and scene packets are rejected so old state cannot overwrite new state.
- Network messages are tied to the current mission generation, which prevents packets from an old scene from affecting the current one.
- Packet shape, sender identity, object ownership, interaction distance, and impossible numbers or transforms are validated before use. Client requests for mission-critical actions are routed through the host while preserving the original sender's identity.
- Reworked dynamic network-object registration and path caching so renamed or removed objects do not leave the session in a broken state. Registrations, queued state, ownership, and voice data are released when the objects or players that created them disappear.
- Reduced unnecessary updates for distant enemies, inactive physics objects, unchanged difficulty, and players outside the mission. Per-frame packet and loading work is limited so large backlogs do not stall the game.
- Multiplayer performance is substantially improved compared with the original CruS Online, including on lower-end computers.
- Added performance and network diagnostics for traffic, processing time, object counts, voice, and scene state. Detailed transport logs can be enabled in debug builds with CRUS_NETWORK_METRICS=1 and disabled with CRUS_NETWORK_METRICS=0. Release builds ignore this logging switch to avoid repeated log work
- Added a Windows crash report watcher that writes the last Godot log lines and available Windows crash details and flushed mission-transition and death-handling steps to the game's crash-reports folder after an unexpected exit. Normal game exits do not create a crash report.
- Improved startup, mission loading, disconnect, and return-to-menu cleanup across both LAN and Steam.
