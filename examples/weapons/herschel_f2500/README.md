# Herschel Firearms F2500

This is an editable custom weapon example. CruS Revitalized supplies the weapon API, but this folder is packaged separately.

From the Online project root, run:

```powershell
python development/tools/build_weapon.py examples/weapons/herschel_f2500 development/artifacts/herschel_f2500/weapon.zip
```

Install the resulting archive at `user://weapons/herschel_f2500/weapon.zip`, then restart the game.
